# Trifecta Advisor website

Static rebuild of trifectaadvisor.co (Home, About, Programs, Contact).
Plain HTML/CSS/JS, no build step. Deploys to Vercel as-is.

- `index.html`, `about.html`, `programs.html`, `contact.html`: pages
- `styles.css`: all styling
- `script.js`: mobile menu, program finder, contact form
- `vercel.json`: lets `/about` work without `.html`

Note: images are currently loaded from the old Hostinger image host
(assets.zyrosite.com). Download them into an `images/` folder before
the Hostinger plan is cancelled.
